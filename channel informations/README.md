# PathshalaBd — বহু ভাষার চ্যানেল ব্র্যান্ডিং

বাংলাভাষীদের জন্য বিভিন্ন ভাষা শেখার চ্যানেলগুলোর সাধারণ ব্র্যান্ড পরিবার: **PathshalaBd**। প্রতিটি ভাষার আলাদা চ্যানেল থাকবে; দর্শকদের সহায়ক ভাষা থাকবে বাংলা।

## নামের নিয়ম

প্রদর্শিত নাম: **{language} Pathshala Bd**। হ্যান্ডেল: **@{language}PathshalaBd**।

এখানে `{language}` হলো শেখানো ভাষার ইংরেজি নাম, যেমন `Hindi`, `English` বা `German`; দেশের নাম বা `hi-BD` ধরনের লোকেল কোড নয়। প্রদর্শিত নামে স্পেস থাকবে; হ্যান্ডেলে স্পেস থাকবে না। `PathshalaBd` বানান ও বড়-ছোট অক্ষর একই রাখুন।

YouTube, Facebook ও Instagram-এ একই ব্র্যান্ড নাম এবং সম্ভব হলে একই হ্যান্ডেল ব্যবহার করুন। হ্যান্ডেলগুলোর প্রাপ্যতা এখনো যাচাই করা হয়নি।
